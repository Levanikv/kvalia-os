# AGENTS.md

Ce dépôt est conçu pour être codé avec des agents (Claude Code, Codex, Cursor…).
**Le guide de référence est [`CLAUDE.md`](./CLAUDE.md)** : règles, carte du repo, boucle de travail, commandes. Lis-le d'abord.

Raccourcis :

- Vérifier avant de livrer : `pnpm check`
- Recettes pas-à-pas : `docs/recettes/` (ajouter un outil, un écran, une migration, un module)
- Décisions déjà prises : `docs/decisions/`
- Conventions de code et d'UI : `docs/conventions.md`
- Routing : `docs/sitemap.md` (source de vérité)

Les fichiers `CLAUDE.md` imbriqués (`packages/core`, `apps/web`, `apps/agent`, `supabase`) donnent les conventions locales de chaque dossier.
