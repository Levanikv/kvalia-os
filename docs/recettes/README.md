# Recettes

Pas-à-pas pour les changements les plus fréquents. Chaque recette finit par **Vérifier** et **Livrer** ; ne saute pas ces étapes.
Les mêmes recettes existent en skills Claude Code (`.claude/skills/`) et en commandes (`/outil`, `/ecran`, `/migration`).

- [Ajouter un outil MCP](ajouter-un-outil.md) — une capacité de l'agent (et de l'app)
- [Ajouter un écran](ajouter-un-ecran.md) — une page dans une app existante
- [Ajouter une migration](ajouter-une-migration.md) — une table, une colonne, une RPC
- [Ajouter un module (app)](ajouter-un-module.md) — une nouvelle application dans le menu
- [Livrer et vérifier sur le téléphone](livrer.md)
