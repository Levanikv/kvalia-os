# Glossaire

Les mots du produit ↔ le code ↔ la base. Quand un terme a plusieurs noms, celui en gras est le bon.

| Terme produit                                                | Code (core / web)                                        | Base                                                                         | Notes                                                                                                                                             |
| ------------------------------------------------------------ | -------------------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Module** / app                                             | `ModuleKey`, `modules` (`packages/ui`)                   | —                                                                            | Home, Quotidien, Sport, Nutrition, Finances, Entreprise, Documents, Objectifs, Réglages, Capture. Sport + Nutrition = une seule app dans le menu. |
| **Vue Jour**                                                 | `VueJour`, RPC `vue_jour`                                | fonction `vue_jour(p_jour, p_user_id)`                                       | La journée agrégée (séance, courses, tâches, habitudes) pour la Home.                                                                             |
| **Capture**                                                  | `/capture`, FAB « + »                                    | `appels_outils` (journal)                                                    | Dire quelque chose à l'agent depuis l'app.                                                                                                        |
| **Liste** (de courses) / **ligne** / **produit** / **rayon** | `liste_actuelle`, `ajouter_produit`                      | `listes`, `lignes`, `produits` (`rayon`)                                     | Une seule liste `active` à la fois ; `manque` = à racheter.                                                                                       |
| **Tâche**, **habitude**                                      | `ajouter_tache`, `Taches`, `Habitudes`                   | `taches`, `habitudes`, `habitudes_log`                                       | Habitude = quotidienne, cochée par jour ; `non_negociable` = affichée en premier.                                                                 |
| **Programme**                                                | `genererProgramme`, `programmes`                         | `programmes` (`actif`, `rythme` jsonb, `materiel`)                           | Un seul actif. Régénérer = remplacer à partir du 1ᵉʳ jour du nouveau (non faites).                                                                        |
| **Bloc**                                                     | `bloc` (1, 2, 3…)                                        | `seances.bloc`                                                               | 4 semaines : 3 de progression + 1 de **décharge** (`deload`).                                                                                     |
| **Semaine x / y**                                            | `positionProgramme()`                                    | `seances.semaine`                                                            | Numéro dans le programme ; affiché sous la bande de jours.                                                                                        |
| **Split**                                                    | `splitPour(nbJours)`                                     | `seances.type`                                                               | 1 → full ; 2 → upper/lower ; 3 → full ×3 ; 4 → upper A / lower A / upper B / lower B ; 5–6 → push/pull/legs.                                      |
| **Séance**                                                   | `seanceDuJour`, `Checklist`                              | `seances` (`etat` : `prevue` → `en_cours` → `faite` / `sautee`)              | `debut_le` = premier exercice coché ; `faite_le` = Terminer.                                                                                      |
| **Exercice de séance** / **prescription**                    | `exercices_seance`, `prescription()`                     | `exercices_seance` (`series`, `reps`, `repos_s`, `duree_s`, `kcal`, `fait`)  | `reps` est une chaîne (« 8-12 », « 8 min »).                                                                                                      |
| **Référentiel d'exercices**                                  | `exercices_ref`, `Ref`, `nomAffiche()`                   | `exercices_ref` (`partie_corps`, `muscles`, `equipement`, `met`, vidéos H/F) | 317 entrées, source free-exercise-db-with-videos. `nom_fr` à remplir ; sinon traduction heuristique.                                              |
| **Créneau** (slot)                                           | `Slot`, `S.pecsCompose`…                                 | —                                                                            | Un emplacement du modèle de séance (muscle cible + nature) que le générateur remplit avec un exercice.                                            |
| **Focus**                                                    | `focus`                                                  | `seances.focus`                                                              | `hypertrophie`, `force`, `mixte`, `deload`.                                                                                                       |
| **Ressenti**                                                 | `ressenti` 1–5                                           | `seances.ressenti`                                                           | Épuisé → Au top, choisi à Terminer.                                                                                                               |
| **Charge**                                                   | `noterCharge`, `historiqueCharge`, `dernieresCharges`    | `exercices_seance.charge_kg`, `realise` jsonb (`reps_faites`, `note`)        | Base des graphes de progression.                                                                                                                  |
| **Remplacer** / **équivalent** / **portée**                  | `equivalents`, `remplacerExercice`, `PorteeRemplacement` | `exercices_seance.substitut_de`                                              | Portée `seance` (celle-ci) ou `programme` (toutes à venir, non faites).                                                                           |
| **MET**                                                      | `met`, `kcalPour`, `MET_SEANCE`                          | `exercices_ref.met`                                                          | kcal = MET × poids (kg) × durée (h). Boxe 7,8 ; cardio 8 ; composé 6 / 5 (poids du corps) ; isolation 4,5 / 3,8.                                  |
| **Poids actuel**                                             | `poidsActuel`                                            | `pesees.poids_kg` → `profils.reglages.sport.poids_kg` → 80                   | Dernière pesée, sinon réglage, sinon défaut.                                                                                                      |
| **Cible du jour**                                            | `bilanJour`                                              | `profils.reglages.nutrition.cible_kcal` + `seances.kcal` du jour             | Base + kcal brûlées (si `ajuster_avec_sport`).                                                                                                    |
| **Paramètres sport** (admin)                                 | `ParametresSport`, `/reglages/sport`                     | `profils.reglages.sport`                                                     | Rythme, jours, durée, matériel, objectif, niveau, semaines, poids de secours.                                                                     |
| **Point d'entrée**                                           | `EntreeCarte`                                            | —                                                                            | Carte vers un sous-module avec un chiffre et une ligne de contexte.                                                                               |
| **Feuille**                                                  | `BottomSheet`                                            | —                                                                            | Modale qui monte du bas, façon iOS.                                                                                                               |
| **Bande de jours**                                           | `BandeJours`, `?jour=`                                   | —                                                                            | Jours scrollables, sélectionné centré, partagée Sport / Nutrition.                                                                                |
| **Menu Applications**                                        | `MenuApps`, `menuApps`                                   | —                                                                            | Burger qui liste les apps ; remplace la tab bar globale.                                                                                          |
| **Barre de l'app**                                           | `ModuleBar`, `onglets`, `barrePour()`                    | —                                                                            | Barre inférieure contextuelle (Sport & Nutri : Jour · Programme · Exercices · Nutrition).                                                         |
| **Outil** (MCP)                                              | `tools`, `executer()`                                    | `appels_outils`                                                              | Une capacité de l'agent ; même contrat côté app. **À confirmer** = `toolsAvecConfirmation`.                                                       |
| **Critère de passage**                                       | —                                                        | —                                                                            | Ce qui doit marcher sur le téléphone pour clore une phase (Notion, Roadmap).                                                                      |
