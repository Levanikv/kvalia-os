Design system · v1

Un shell, des mini-apps.

Primitives → Brand (une identité par mini-app) → Theme (light/dark) → Layout · Typography · Motion → Components. Change la mini-app, le thème, la densité ou le motion en haut : tout se recompose depuis les mêmes tokens.

Architecture

8 collections, chaque couche ne référence que les couches en dessous. Le build refuse toute violation.

Matrice mini-apps × thèmes

Mêmes composants, mêmes tokens sémantiques. Seuls les attributs data-brand / data-theme changent.

Couleur · Primitives

Typographie

Display / headline suivent la police de la mini-app. Desktop (≥ 1024 px) agrandit display, headline et numeric.
